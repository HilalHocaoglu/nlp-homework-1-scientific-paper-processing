# Course PDF inputs

Place the nine course-provided PDFs in this directory using the filenames
below. The notebook and command-line examples read from this project folder,
not from a user's Downloads directory.

The PDF binaries are intentionally excluded from Git for now. These are
third-party research papers, and redistribution rights must be checked for the
exact supplied versions before publishing copies in a public repository. The
links below point to the papers' original scholarly sources; they are provided
for identification and retrieval, not as a blanket license to redistribute.
